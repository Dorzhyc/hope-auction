# hope-auction — MVP аукциона на 35 лотов

Функции:
- Публичный каталог лотов + страница лота
- Ставки без аккаунта (email + ник + сумма)
- Шаг 10% с округлением вверх до 100 ₽
- Отклонение ставок: ниже min_bid, >= 20x текущей, после окончания аукциона
- Публичная история ставок (ник/сумма/время до минут, МСК)
- Админка: CRUD лотов, настройка окончания, финализация победителей, журнал событий, экспорт CSV
- Rate limit: не более 3 ставок/мин по IP

## Быстрый запуск локально

1) Установите Node.js 18+ и PostgreSQL 14+
2) Создайте БД:
   - `createdb hope_auction`
3) Скопируйте `.env.example` -> `.env` и заполните `DATABASE_URL` и `ADMIN_PASSWORD`
4) Установите зависимости:
   - `npm i`
5) Примените миграции и сид:
   - `npm run db:migrate`
   - `npm run db:seed`
6) Запуск:
   - `npm run dev`
   - Откройте `http://localhost:3000`

## Деплой
- Front+API можно держать на одном хостинге (например Render/Fly).
- PostgreSQL — managed (Render/Fly/Supabase).
- Для изображений подключите S3/R2 и сохранение URL в `lot_images` (в MVP заглушка).

## Важное
- ADMIN_PASSWORD хранится в env, вход — через cookie.
- Для продакшена рекомендуется: нормальные сессии, 2FA, отдельный Redis для rate limiting, CDN для изображений.
